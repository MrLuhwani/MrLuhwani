### 🌱 Things I've Done? 

- [Session Authentication Api](https://github.com/MrLuhwani/Session-auth-login-api) - A session based authentication system built with java, Spring boot, and Spring security 6. I was able to take care of some common web security concerns such as CSRF, session fixation, brute-force protection and concurrent sessions.
- [Finance Ledger](https://github.com/MrLuhwani/Finance-Ledger) - A CRUD CLI for tracking income and expense, currently being evolved toward a Spring Boot backend.

### Currently Working on?
- [Tweet Audit](https://github.com/MrLuhwani/tweet-audit) - The first project of [BenX's](https://github.com/benx421) backend engineer path. The core task: Process your X (Twitter) archive, evaluate each tweet against your alignment criteria using Gemini AI, and generate a CSV of flagged tweets for deletion. This project is to teach me: 
    - HTTP client patterns and third-party API integration (Google Gemini), 
    - Rate limiting and backpressure handling
    - Concurrent processing patterns (batching vs sequential vs full async)
    - Error recovery strategies (retry logic, checkpointing, partial failures)
    - State management (tracking processed tweets, resumable workflows)
    - Configuration management and secrets handling
    - Writing testable code with external dependencies
